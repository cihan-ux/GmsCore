# Changelog

## 2.0.0 (development)

- New branding: Huawei GMS Diagnostics
- Separate checks for GSF, GMS, and Play Store protected permissions
- Diagnostic distinction between permissions requested by an APK and granted by Android
- Read-only diagnostics for Google Services Framework MANAGE_USERS issues
- Google authenticator owner package visibility
- GMT and Huawei signature diff package presence checks
- Optional local clipboard, TXT save and Android share
- Explicit privacy policy and release checklist

## 1.0.0

- First rootless GmsCore HW Assistant scan UI, signature checks and account type visibility
